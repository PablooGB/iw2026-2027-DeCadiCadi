# DeCadiCadi

Plataforma web para la gestión del Concurso Oficial de Agrupaciones Carnavalescas de Cádiz (COAC) y la conservación de la memoria histórica del Carnaval.

## Objetivos

- Facilitar la gestión de las ediciones del concurso.
- Consultar agrupaciones, autores, repertorios y resultados.
- Conservar y consultar el archivo histórico del Carnaval.
- Gestionar las inscripciones, las fases y la programación.
- Proporcionar acceso a la información según los permisos de cada usuario.
