# AGENTS.md — DeCadiCadi

## Tecnologías

- Java 21.
- Spring Boot 4.
- Vaadin 25.
- Apache Maven.

## Convenciones de desarrollo

- Seguir las convenciones de Java y mantener nombres claros y descriptivos.
- Separar responsabilidades y evitar duplicación innecesaria.
- Validar los datos recibidos por la aplicación.
- Mantener las credenciales y secretos fuera del repositorio.
- Añadir pruebas para las funcionalidades y correcciones relevantes.
- Ejecutar las pruebas antes de integrar cambios.
- Mantener actualizada la documentación afectada.
- Utilizar mensajes de commit descriptivos.
- Revisar el código mediante Pull Requests.

## GitHub

- Registrar el trabajo en Issues.
- Relacionar los Pull Requests con las Issues correspondientes.
- No cerrar una tarea hasta comprobar sus criterios de aceptación.
- Mantener el estado de las incidencias actualizado.

## Uso de IA

- Declarar en la documentación las herramientas de IA utilizadas y su finalidad.
- Revisar y probar cualquier contenido generado.
- No incorporar código que el equipo no comprenda.
- No introducir datos personales, credenciales ni información confidencial en herramientas externas.
- La responsabilidad de los cambios corresponde a las personas que los revisan e integran.
