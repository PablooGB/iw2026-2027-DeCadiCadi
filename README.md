# DeCadiCadi

Plataforma web para la gestión del Concurso Oficial de Agrupaciones Carnavalescas de Cádiz (COAC) y la conservación de la memoria histórica del Carnaval.

## Objetivos

- Facilitar la gestión de las ediciones del concurso.
- Consultar agrupaciones, autores, repertorios y resultados.
- Conservar y consultar el archivo histórico del Carnaval.
- Gestionar las inscripciones, las fases y la programación.
- Proporcionar acceso a la información según los permisos de cada usuario.

## Tecnologías

- **Lenguaje:** Java 21.
- **Framework backend:** Spring Boot 4.
- **Framework de interfaz web:** Vaadin 25.
- **Gestión de dependencias y construcción:** Apache Maven.
- **Control de versiones y colaboración:** Git y GitHub.
- **Integración continua:** GitHub Actions.
- **Despliegue:** AWS.

## Gestión del proyecto

El equipo trabajará con Scrum, organizando el desarrollo en sprints de entre dos y tres semanas. Se utilizarán las Issues de GitHub para gestionar tareas, historias de usuario e incidencias, y las Pull Requests para revisar los cambios antes de integrarlos en la rama principal.
